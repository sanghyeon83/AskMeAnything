# screen-control — 화면 보기·조작

`screen.ps1` 하나로 캡처·창·마우스·키보드를 전부 처리한다.

```bash
powershell -NoProfile -ExecutionPolicy Bypass -File "%USERPROFILE%\.claude\skills\screen-control\screen.ps1" -Action <동작> [옵션]
```

## 동작 목록

| 동작 | 필수 인자 | 하는 일 |
|---|---|---|
| `info` | — | 화면 크기·커서·창 개수. **작업 전에 먼저 찍어 좌표계를 확인한다** |
| `capture` | — | 화면 저장. `-Region "x,y,w,h"` 로 영역만, `-Scale 0.5` 로 축소, `-Out` 로 경로 지정 |
| `windows` | — | 보이는 창 전부(hwnd·PID·프로세스·좌표·크기·최소화). `-Filter` 로 제목/프로세스 부분일치 |
| `front` | `-Title` 또는 `-Handle` | 창을 앞으로. 최소화면 복원한다 |
| `click` | `-X -Y` | 클릭. `-Button right\|middle`, `-Double` |
| `move` | `-X -Y` | 커서 이동만 |
| `scroll` | `-X -Y` | 휠. `-Amount` 양수=위, 음수=아래 |
| `type` | `-Text` | 유니코드 그대로 입력. **한글 안전** (SendInput 유니코드 방식) |
| `key` | `-Text` | 단축키. SendKeys 문법 (`^s`, `%{F4}`, `{ENTER}`, `^z`) |
| `cursor` | — | 현재 커서 좌표 |

## 좌표계 — 제일 많이 틀리는 부분

스크립트는 시작하자마자 `SetProcessDPIAware()` 를 부른다. **모든 좌표가 물리 픽셀이다.**

| | 값 (이 PC) |
|---|---|
| 물리 픽셀 (이 스킬이 쓰는 값) | **1920 x 1200** |
| 논리 좌표 (DPI 미인식 PowerShell 기본값) | 1536 x 960 |
| 배율 | 125% |

그냥 띄운 PowerShell에서 `[System.Windows.Forms.Cursor]::Position` 같은 걸로 좌표를 재면
**논리 좌표**가 나와서 이 스킬의 좌표와 어긋난다. 좌표는 반드시 이 스크립트로 구할 것
(`windows` 의 창 좌표, `cursor`, `capture` 가 찍어주는 원본영역).

## 일하는 순서

1. `info` 로 화면 크기를 확인한다.
2. `windows -Filter <앱>` 으로 대상 창의 hwnd 와 좌표를 얻는다.
3. `front` 로 앞에 세운다. **배경 창에는 클릭이 엉뚱하게 들어간다.**
4. `capture -Region` 으로 그 창만 찍어 **눈으로 확인하고 좌표를 정한다.**
5. `click` / `type` / `key` 로 조작한다.
6. `capture` 로 **결과를 확인한다.** 눌렀다고 눌린 게 아니다.

## ⚠️ 시험 대상을 고를 때 — 2026-09-08에 실제로 사고 났다

**사용자가 쓰고 있는 앱에 시험 삼아 입력하지 마라.**

메모장으로 클릭·입력을 검증하다가 사고가 났다. Windows 11 메모장은
`Start-Process notepad` 를 해도 **새 창을 띄우지 않고 기존 인스턴스에 붙는다.**
그래서 시험 문자열이 사용자가 쓰던 미저장 메모에 그대로 들어갔다.
`key -Text '^z'` 한 번으로 되돌렸지만, 한 번 더 눌렀으면 사용자의 편집분이 지워질 뻔했다.

지킬 것:

- 입력 시험은 **내가 만든 빈 파일**을 그 앱으로 직접 열어서 한다.
- 창 제목에 `*` 가 있으면 **미저장 변경분이 있다는 뜻이다.** 건드리지 마라.
- 입력하기 전에 `capture` 로 **그 자리에 뭐가 있는지 먼저 본다.**
- 되돌릴 때 `^z` 는 **한 번 누르고 확인한다.** 연타하면 남의 작업을 지운다.
- 시험이 끝나면 원래 상태로 돌려놓고, **되돌렸다는 사실을 사용자에게 말한다.**

## 하지 말아야 할 것

- **비밀번호·카드번호·주민번호·API 키를 입력하지 않는다.** 어떤 필드에도.
- **캡차를 풀지 않는다.**
- **다른 도구에서 거부된 동작을 이 스킬로 우회하지 않는다.** 권한 분류기가 브라우저
  조작을 막았다면, 같은 일을 합성 마우스 클릭으로 하는 것도 막힌 것이다.
  막혔으면 사용자에게 알리고 사용자가 정하게 한다.
- **화면 전체 캡처는 남의 사생활이 같이 찍힌다.** 메신저·메일·메모가 열려 있다.
  가능하면 `-Region` 으로 필요한 창만 찍고, 전체 캡처는 사용자에게 되돌려 보내지 않는다.
- 되돌리기 어려운 버튼(삭제·전송·결제·확인)은 **누르기 전에 물어본다.**

## 알려진 제약

- **`front` 가 실패할 수 있다.** 다른 앱이 포그라운드를 잠그면 Windows가 거부한다.
  ALT 키를 눌러 락을 푸는 우회를 이미 넣었지만 100%는 아니다. 종료코드 1 로 알려준다.
- **`type` 은 포커스가 있는 곳에 들어간다.** `front` + `click` 으로 포커스를 먼저 잡아라.
- **캡처는 화면에 보이는 것만 찍는다.** 가려진 창은 가린 창이 찍힌다. `front` 먼저.
- 관리자 권한으로 뜬 창(UAC 승격된 앱)은 일반 권한 프로세스가 조작할 수 없다.
- UAC 동의 대화상자 자체는 보안 데스크톱이라 캡처도 클릭도 안 된다.

## 관련

- 브라우저 안의 일이면 `mcp__claude-in-chrome__*` 가 더 정확하다 — DOM 을 읽으니
  좌표를 추측하지 않아도 된다. **이 스킬은 그게 안 닿는 곳에 쓴다.**
- 세션 간 대화는 [[talk]] · [[peer-talk]] · [[cross-talk]].
